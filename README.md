# 타닥 (Tadak) - 기계식 키보드 소리·햅틱 아이폰 키보드

축(스위치)마다 다른 타건음과 터치 진동이 나는 아이폰 커스텀 키보드입니다.
두벌식 한글 + 영문 + 숫자/기호 자판, 6개 축, 흡음재 on/off, 그리고 직접 녹음한 **내 소리**를 지원합니다.
"타닥"은 임시 이름입니다. (바꾸는 법은 맨 아래)

## 들어 있는 것

| 위치 | 역할 |
|---|---|
| `App/` | 앱 본체 화면 - 축 선택, 미리 쳐보기, 소리·진동 설정, 키보드 추가 안내 |
| `Keyboard/` | 실제 키보드 - 자판 배열, 한글 조합, 입력 처리 |
| `Shared/` | 앱과 키보드가 같이 쓰는 코드 - 축 정의, 소리 재생, 진동 |
| `Shared/Sounds/` | 타건음 WAV 104개 - 실제 스위치 녹음 (6축 x 흡음재 유무) |
| `tools/build_sounds.py` | 원본 녹음에서 타건음 파일을 다시 잘라 내는 스크립트 |
| `Licenses/` | 녹음 원본(Mechvibes, kbsim)의 MIT 라이선스 전문 |
| `project.yml` | Xcode 프로젝트 자동 생성 설정 (XcodeGen) |
| `.github/workflows/build.yml` | 깃허브 맥 서버 자동 빌드 설정 |

## 윈도우 PC로 아이폰에 넣기

코드를 `tadak` 브랜치에 올리면 깃허브의 맥 서버가 자동으로 빌드해서 Releases에 설치 파일을 올립니다.
(빌드 1번에 1~2분. 확인: 저장소의 Actions 탭)

1. **설치 파일 받기** - PC에서 아래 주소를 열면 가장 최근 빌드가 받아집니다.
   https://github.com/whwh1231-gif/cls_data/releases/download/tadak-latest/Tadak.ipa
2. **Sideloadly 준비** - PC에 Sideloadly를 설치합니다. 윈도우는 iTunes와 iCloud가 필요하고,
   Microsoft Store 버전이 아닌 애플 홈페이지 버전이어야 합니다.
3. **설치** - 아이폰을 USB로 연결한 뒤 IPA를 Sideloadly에 끌어다 놓고 Apple ID로 로그인, Start.
4. **아이폰에서 허용** - 설정 > 일반 > VPN 및 기기 관리에서 신뢰,
   설정 > 개인정보 보호 및 보안 > 개발자 모드 켜기.
5. **키보드 켜기** - 설정 > 일반 > 키보드 > 키보드 > 새로운 키보드 추가 > 타닥.
   추가된 타닥을 다시 눌러 **전체 접근 허용**을 켜야 소리와 진동이 나옵니다.

무료 Apple ID 설치는 7일 뒤 만료됩니다(3번 반복). 또 이 방식에서는 앱 화면의 설정이
키보드로 전달되지 않을 수 있어, 키보드 위쪽 바에서 축과 흡음재를 직접 바꿀 수 있게 했습니다.
정식 배포(TestFlight, 앱스토어)는 Apple Developer Program(연 99달러) 가입 후 가능합니다.

## 소리·진동 손보기

- **축별 진동**: `Shared/SwitchType.swift`의 `haptic` 부분. 종류(light/medium/heavy/soft/rigid)와 세기(0~1)만 바꾸면 됩니다.

  | 축 | 누를 때 | 뗄 때 |
  |---|---|---|
  | 적축 | light 0.60 | - |
  | 갈축 | medium 0.65 | - |
  | 흑축 | heavy 0.75 | - |
  | 청축 | rigid 0.95 | light 0.45 |
  | 크림축 | soft 0.95 | - |
  | 아크 라벤더 | rigid 0.65 | soft 0.35 |

- **축별 소리**: 실제 기계식 스위치 녹음입니다. (v2에서 합성음을 전부 교체)

  | 축 | 녹음 원본 |
  |---|---|
  | 적축 / 갈축 / 흑축 / 청축 | Mechvibes - Cherry MX Red / Brown / Black / Blue (PBT 키캡) |
  | 크림축 | kbsim - NovelKeys Cream |
  | 아크 라벤더 | Mechvibes - EG Crystal Purple (아크 라벤더 공개 녹음이 없어 가장 가까운 택타일로 대체) |

  이름 규칙은 `{축}_{o|d}_{down1..5|up1..2|space|spaceup}.wav` (o = 기본, d = 흡음재).
  번호가 붙은 파일은 있는 만큼 읽어 무작위로 섞어 재생하므로, 파일을 더 넣거나 바꾸기만 하면 됩니다.
  흡음재 버전은 별도 녹음이 아니라 같은 녹음에서 잔향과 고음을 줄여 만든 것입니다.
- **라이선스**: 두 원본 모두 MIT 라이선스라 상업적 이용이 가능하고, 조건인 저작권 고지는 앱의
  "오픈소스 고지"에 넣어 두었습니다. 다만 Mechvibes 팩 일부는 커뮤니티가 올린 녹음이라 개별 출처가
  문서로 남아 있지 않습니다. 유료로 스토어에 올릴 때는 직접 녹음하거나 출처가 분명한 샘플로 바꾸는 편이 안전합니다.
- **내 소리**: 앱의 "내 소리 녹음"에서 최대 2초를 녹음하거나, "파일에서 가져오기"로 이미 있는
  소리 파일(m4a, mp3, wav 등)을 고르면 키를 누를 때마다 그 소리가 납니다.
  음성 메모는 공유 > "파일에 저장"으로 옮겨 두면 고를 수 있고, 긴 파일은 소리가 시작되는 곳부터 2초만 씁니다.
  앞뒤 무음은 자동으로 잘리고 음량도 맞춰집니다. 길어서 겹치면 시끄럽기 때문에, 빠르게 치면
  앞 소리를 끊고 새로 재생합니다. 뗄 때 소리와 흡음재는 적용되지 않습니다.
  녹음은 앱에서만 됩니다(아이폰은 키보드에 마이크를 허용하지 않음). 녹음 파일을 키보드가 읽으려면
  앱 그룹(공유 폴더)이 필요해서, **무료 Apple ID 설치에서는 키보드에서 내 소리가 안 날 수 있습니다.**
  이 경우 앱 화면에 주황색 안내가 뜨며, Apple Developer Program으로 정식 서명하면 해결됩니다.
  다듬는 규칙은 `Shared/CustomSound.swift`의 `trimmed`에 있습니다.
- **무음 모드**: 기본은 아이폰 무음 스위치를 따릅니다. 앱 설정의 "무음 모드에서도 재생"으로 바꿀 수 있습니다.

## 검증한 것과 못 한 것

- 한글 조합기: 실제 Swift 컴파일러로 컴파일해 31개 입력 케이스 통과 (겹받침, 겹모음, 지우기 포함)
- 키보드·공용 코드: UIKit 뼈대를 흉내 낸 환경에서 타입 검사 통과
- 내 소리: 녹음 다듬기 로직을 실제 Swift 컴파일러로 실행해 12개 케이스 통과(무음 제거, 버튼 소리 제외, 최대 2초, 48kHz 파일 음높이 유지 등). 마이크 녹음과 파일 공유는 아이폰 전용 기능이라 실기기 확인이 필요합니다.
- 타건음: 104개 전부 파형 검사(누르는 소리 지연 1.3ms 이하, 찌그러짐 없음), 미리듣기 페이지에서 전 조합 재생 확인. 단, 귀로 들어 보는 검수는 못 했습니다.
- 앱 화면(SwiftUI): 문법 검사만 통과
- 아이폰 빌드: 깃허브 맥 서버(Xcode 26)에서 오류 없이 성공. IPA 안에 앱, 키보드 확장, 소리 104개, 마이크 권한 문구가 들어 있는 것 확인.
- **실기기 테스트는 아직 못 했습니다.**
  소리 지연, 진동 세기, 커서 이동 직후의 한글 조합은 실기기에서 써 보며 조정이 필요합니다.

`project.yml`의 `com.woo.tadak` 두 군데(앱, 키보드)와 `group.com.woo.tadak` 두 군데,
